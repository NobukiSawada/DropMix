# ローカルPDF・画像処理アプリ「DropMix」 開発要件定義書

あなたはフルスタックエンジニアです。以下の要件定義に基づき、完全ローカルで動作する高速かつモダンなデスクトップアプリ「DropMix」の実装をお願いします。

## 1. プロジェクト概要
- **アプリ名**: DropMix
- **目的**: Webサービスを使わずに、ローカル環境でセキュアかつ高速にPDF・画像を編集・変換できるデスクトップアプリケーションの開発。
- **特徴**: モダンでシンプルなUI、直感的なドラッグ＆ドロップ操作、PDFと画像のシームレスな混在処理。

## 2. 技術スタック
- **フロントエンド**: React (Vite), TypeScript, Tailwind CSS
  - コンポーネント: shadcn/ui または Radix UI (モダンでシンプルなUIのため)
  - ファイルドロップ: react-dropzone
  - ドラッグ＆ドロップ並び替え: @dnd-kit/core または類似のモダンライブラリ
  - アイコン: lucide-react
- **バックエンド**: Python, FastAPI
  - PDF処理: PyMuPDF (`fitz`) - 速度重視
  - 画像処理: Pillow
  - マルチパート通信: python-multipart
- **デスクトップアプリ化**: PyWebView (バックグラウンドでFastAPIを動かしUIを表示)
- **パッケージング・CI/CD**: PyInstaller (Windows用 .exe化), GitHub Actions (自動ビルド＆リリース)

## 3. 機能要件 (Functional Requirements)

### 3.1 コア機能（優先実装）
1. **PDFと画像の混在結合 (Merge)**
   - 複数のPDFおよび画像(JPG/PNG)を受け取る。
   - 画像は自動的にPDFに変換され、指定された順序で1つのPDFとして高速に結合・出力される。
2. **プレビューと並び替え (Preview & Sort) ※重要**
   - 追加されたファイルの各ページ・画像をサムネイルでプレビュー表示する。
   - サムネイルをドラッグ＆ドロップして、結合や処理の順番を直感的に入れ替えられるようにする。
3. **PDFの分割・抽出 (Split / Extract)**
   - 全ページを個別のPDFに分割。指定範囲のみの抽出。
4. **PDFから画像への変換 (PDF to JPG)**
   - 全ページ、または指定ページを高画質なJPG/PNGとして一括出力。

### 3.2 編集・加工機能
5. **PDFの圧縮 (Compress PDF)**
   - PyMuPDFの最適化オプション(`garbage=4`, `deflate=True`)を利用しファイルサイズを軽量化。
6. **ページの回転と削除 (Rotate & Delete Pages)**
   - 特定のページの回転（90度ずつ）および削除。
7. **透かし・ページ番号 / セキュリティ保護**
   - 透かしテキストの追加、パスワードの付与・解除。

## 4. UI/UX要件
- **デザインテーマ**: **「白」を基調とし、アクセントカラー（差し色）に「緑」を使用。** 清潔感があり、安心感を与えるモダンなデザイン。
- **インタラクション**:
  - 全画面に近い大きなドラッグ＆ドロップエリア。
  - サムネイルはグリッド表示にし、D&Dでの並び替えをスムーズにアニメーションさせる。
  - 処理中や完了時は、緑色を基調としたスナックバー/トースト通知やプログレスバーを表示。

## 5. パッケージングとCI/CD要件
- **実行ファイル化**: 
  - PyInstallerを使用し、Python環境がないWindows PCでもダブルクリックで起動できる単一の `.exe` ファイルを作成する。
- **GitHub Actions**: 
  - mainブランチへのPush（またはTagプッシュ）をトリガーに、以下のパイプラインを実行する。
    1. フロントエンド (Vite) のビルド。
    2. バックエンドとフロントエンドのビルド成果物を統合。
    3. PyInstallerによるWindows向け `.exe` のビルド。
    4. GitHub Releases への成果物 (`DropMix.exe`) の自動アップロード。

## 6. 実装の進め方（フェーズ分け）
Claudeには、以下のフェーズ順に実装を依頼します。まずは **Phase 1** のコードを生成してください。

- **Phase 1: プロジェクトのセットアップと最小構成API**
  - ViteとFastAPIのディレクトリ構成作成。
  - PyWebViewの起動スクリプト (`main.py`) 。
  - 「PDFと画像の混在結合機能」のバックエンドAPI実装。
- **Phase 2: UI構築 (白×緑テーマ) と プレビュー・並び替え**
  - Tailwind CSS + shadcn/ui を用いたテーマ設定（白基調＋緑アクセント）。
  - react-dropzoneとdnd-kitを使った、サムネイル表示＆並び替えUIの実装。
- **Phase 3: 各種機能の追加**
  - 分割、圧縮、画像変換など、残りの主要APIの実装と画面追加。
- **Phase 4: パッケージングとGitHub Actions**
  - PyInstallerの `.spec` ファイルの作成とビルドスクリプト。
  - `.github/workflows/build.yml` の作成。
